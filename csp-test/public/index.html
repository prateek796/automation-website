FAQ

How do I switch CSP modes?

Visit /block-worker, /allow-worker, /report-only, /no-csp, or /strict/*. CSP shapes differ per route, but worker-src 'none' is applied on every page.

Does this page include VWO?

Yes. Async SmartCode is in <head>. VWO can load on VWO-allowing routes; Workers are always blocked. Pass ?id=ACCOUNT to override the account, or ?wingify for the edge CDN path.

Will workers run on every route?

No. Workers are blocked site-wide via worker-src 'none' on all HTML routes. Check the console and QA panel for the CSP error.

Are assets local-only?

Yes — CSS, JS, worker, logo, favicon, and product SVGs are served from this origin. VWO loads from its CDN when CSP permits.

How do I expose this publicly?

Run ngrok http 3000 and point VWO / your analyzer at the HTTPS tunnel URL.
